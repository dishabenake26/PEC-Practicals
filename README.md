# Data Manipulation and Visualization Using Excel

## 📌 Overview

This practical focuses on performing **data manipulation, analysis, and visualization using Microsoft Excel**. It covers basic techniques for organizing data, preprocessing it, and representing information using charts.

## 🎯 Aim

To perform data manipulation and visualization using Microsoft Excel.

## 🛠️ Software Used

* **Microsoft Excel 2010**

## 📚 Topics Covered

* Data organization and preparation
* Data manipulation
* Sorting and filtering
* Data preprocessing
* Feature selection
* Statistical analysis
* Data visualization
* Charts and graphs
* Histogram

## 📊 Practical Work

The practical includes working with a dataset in Excel and performing operations such as:

1. Organizing and preparing the dataset
2. Manipulating and preprocessing the data
3. Identifying and handling outliers
4. Selecting relevant features
5. Creating charts for data visualization
6. Creating a histogram to understand data distribution

## 📈 Visualization

Different Excel charts can be used to represent the processed data and identify patterns, trends, and distributions within the dataset.

## 💡 Learning Outcomes

After completing this practical, I learned how to:

* Work with datasets in Microsoft Excel
* Manipulate and preprocess data
* Identify and handle outliers
* Select relevant features
* Create charts and visualizations
* Use histograms to analyze data distribution
